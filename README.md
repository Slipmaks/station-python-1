# Станція «Пітон-1»

Гра для уроків Python (інформатика, 9 клас): учні відновлюють космічну станцію, розв’язуючи задачі.
Учитель створює клас і дає учням код; учні входять за кодом класу, іменем і PIN, а прогрес і кожна спроба зберігаються в БД.
Відповіді перевіряє сервер: код учня виконується тим самим інтерпретатором, що й у браузері, а зірки рахуються з журналу спроб.
SvelteKit 3 + Svelte 5, БД — SQLite (libSQL / Turso) через Drizzle, деплой на Vercel.

## Локальний запуск

```sh
npm install
cp .env.example .env                       # DATABASE_URL=file:local.db
npm run db:migrate                         # створити таблиці
npm run teacher -- olena "Олена Петрівна"  # учитель; пароль буде надруковано
npm run dev                                # http://localhost:5173
```

Учитель входить на `/teacher/login`, створює клас і бачить його код. Учні — на `/login`:
після входу — сторінка уроків (`/`), далі станція уроку (`/l/<урок>`) і її відсіки (`/m/<відсік>`).
Той самий `npm run teacher -- <логін>` видає новий пароль, якщо старий загубився.

## Кабінет учителя

- **Мої класи** (`/teacher`) — класи з кодами, створення нового класу.
- **Клас** (`/teacher/c/<id>`) — вкладки уроків: учитель відкриває чи закриває урок класу (новому класу відкрито перший урок;
  учні бачать зміну за кілька секунд, без перезавантаження). Під вкладкою — таблиця «учні × відсіки» вибраного уроку:
  зірки за пройдені відсіки, кількість спроб у розпочатих, жовтим — 5+ невдалих спроб без проходження («варто підійти»).
  Оновлюється кожні 20 секунд. Тут же — код для входу й перемикач «Відкрити всі відсіки» (у всіх уроках).
- **Учень** (`/teacher/c/<id>/s/<id>`) — усі спроби по уроках і відсіках із кодом, який запускав учень (до 20 останніх на відсік);
  «Видати новий PIN» (знімає блокування й завершує всі сесії учня) і «Видалити учня» разом з усіма його даними.

Учитель бачить лише свої класи; чужі сторінки й дії відповідають 404.

```sh
npm test          # вміст уроків, правила зірок, безпека входу, перевірка даних API
npm run check     # типи
npm run test:e2e  # гра, вхід, кабінет, підробки, уроки — у справжньому браузері (~2 хв)
```

E2E (`e2e/`, Playwright) самі запускають dev-сервер на порту 5199 зі свіжою БД `e2e.db` і використовують установлений
Google Chrome (немає Chrome — `npx playwright install chromium` і прибрати `channel` у `playwright.config.ts`).
Будь-яка помилка в консолі браузера валить тест. Звіт про невдалий прогін зі знімками й трасою — `npx playwright show-report`.

## Деплой: Turso + Vercel

1. БД у Turso:
   ```sh
   turso db create pyton1
   turso db show pyton1 --url          # → DATABASE_URL
   turso db tokens create pyton1       # → DATABASE_AUTH_TOKEN
   ```
2. Таблиці й перший учитель у продакшн-БД (змінні з оточення мають пріоритет над `.env`):
   ```sh
   DATABASE_URL=libsql://… DATABASE_AUTH_TOKEN=… npm run db:migrate
   DATABASE_URL=libsql://… DATABASE_AUTH_TOKEN=… npm run teacher -- olena "Олена Петрівна"
   ```
3. Vercel: імпортувати репозиторій, у Settings → Environment Variables задати `DATABASE_URL` і `DATABASE_AUTH_TOKEN`.

Після зміни схеми БД (`src/lib/server/db/schema.ts`): `npm run db:generate`, потім `npm run db:migrate` — локально й для Turso.

## Структура

| Шлях | Що там |
|---|---|
| `src/lib/lessons/` | Уроки: `intro.ts` — урок 1, `lists.ts` — урок 2 (ще готується), `index.ts` — реєстр і порядок уроків |
| `src/lib/types.ts` | Формат уроку й відсіку (`Lesson`, `Mission`) — підказки редактора під час написання уроків |
| `src/lib/py.js` | Навчальний інтерпретатор підмножини Python (працює і в браузері, і на сервері) |
| `src/lib/grade.ts` | Перевірка розв’язку й правила зірок — чисті функції без DOM, спільні для браузера й сервера |
| `src/lib/state.svelte.ts` | Стан гри в браузері |
| `src/lib/sync.svelte.ts` | Черга запитів до сервера: без зв’язку повторює, нічого не губить |
| `src/lib/server/` | БД (`db/schema.ts`), сесії, PIN і паролі, перевірка даних API, перевірка відповідей і зірок (`judge.ts`), таблиця результатів (`report.ts`) |
| `src/routes/(game)/` | Гра — лише для учнів, без SSR: уроки, станція уроку, відсіки, пісочниця |
| `src/routes/login` | Вхід учня |
| `src/routes/teacher/` | Вхід і кабінет учителя: класи, таблиця результатів, сторінка учня |
| `src/routes/api/` | Збереження: робочий стан і спроби; спроба, що завершує відсік, записує зірки |
| `e2e/` | E2E-тести (Playwright): спільні помічники — `helpers.ts` |
| `scripts/teacher.ts` | Створити вчителя / видати новий пароль |
| `drizzle/` | Міграції БД |
| `legacy/` | Початкова офлайн-версія в одному HTML |

## Що зберігається в БД

- `progress` — пройдені відсіки, найкращий результат у зірках;
- `attempts` — кожна спроба: код або відповідь, чи правильно (вирішує сервер), скільки підказок відкрито, чи відкривався розв’язок;
  у спроби, що завершила відсік, — зірки (наступні спроби рахуються вже як нове проходження);
- `workspaces` — чернетки коду й лічильники підказок/помилок (JSON на учня);
- `students` — ім’я, хеш PIN; після 5 неправильних PIN поспіль вхід блокується на 10 хвилин;
- `classes` — код класу, «Відкрити всі відсіки» й уроки, які вчитель відкрив класу.

## Як додати відсік чи урок

1. Відсік — об’єкт у `missions` у файлі уроку (`src/lib/lessons/intro.ts`). Тип `Mission` підкаже поля:
   `kind: 'code'` — задача з кодом, `'choice'` — вікторина, `'types'` — сканер типів.
   `id` має бути унікальним серед усіх уроків — це ключ у БД.
2. Для задачі з кодом обов’язкові `starter`, `solution` і `checks` — функції, що отримують
   `{ src, res, out, inputs }` і повертають `true`/`false`. Готові помічники — у `src/lib/checks.ts`.
3. Новий урок — новий файл у `src/lib/lessons/` (за зразком `intro.ts`) і рядок у `index.ts`; номер уроку — його місце в списку.
   Урок з порожнім `missions` показується як «готується» (так зараз `lists.ts`). Щойно з’являться відсіки, потрібен `certificate`,
   а вчитель відкриває урок класу в кабінеті. `id` уроку — ключ у БД (відкриті уроки класів): після публікації не змінювати.
4. `npm test` — переконайся, що еталонний розв’язок проходить, а стартовий код — ні.

Інтерпретатор не підтримує `def`, `class`, `try` і словники — для уроків про них його доведеться розширити.
